# パスワード生成ツール

## 概要

このプロジェクトは、推測されにくい強固なパスワードを生成するためのWebアプリケーションです。ユーザーは文字種、文字数、覚えやすいキーワードを指定することで、セキュリティ要件を満たしつつも、記憶の助けとなるようなカスタムパスワードを作成できます。

## 主な機能

- **文字種のカスタマイズ**: 以下の文字種を自由に組み合わせて使用できます。
  - 英語（大文字）
  - 英語（小文字）
  - 数字
  - 記号 (`!@#$%^&*()`など)
- **文字数の指定**: パスワードの長さを8, 10, 12文字から選択、または任意の数値を指定できます。
- **キーワードの組み込み**: 覚えやすい単語をパスワードのベースとして使用できます。
- **文字変換**: パスワードをより強固にするため、指定した単語内の特定の文字が自動で変換されます。
  - `l` → `1`, `o` → `0`, `s` → `5`, `q` → `9`, `b` → `8`

## 動作要件

- [Docker](https://www.docker.com/)
- [Docker Compose](https://docs.docker.com/compose/) (Docker Desktopに含まれています)

## 起動方法

1.  このリポジトリをクローンまたはダウンロードします。
2.  ターミナルでプロジェクトのルートディレクトリに移動します。
3.  以下のコマンドを実行して、Dockerコンテナをビルドし、バックグラウンドで起動します。

    ```bash
    sudo docker compose up -d --build
    ```

4.  ビルドと起動が完了したら、Webブラウザで以下のURLにアクセスします。

    [http://localhost:5001](http://localhost:5001)

## 使い方

1.  **使用する文字の種類**: パスワードに含めたい文字種（大文字、小文字、数字、記号）のチェックボックスを選択します。
2.  **文字数**: 希望するパスワードの長さを選択します。「その他」を選ぶと、数値を直接入力できます。
3.  **覚えやすい単語**: パスワードのベースにしたい単語を任意で入力します。（例: `Apple`, `Soccer`）
4.  **「パスワードを生成」ボタンをクリック**: ボタンを押すと、指定された条件に基づいてパスワードが生成され、画面に表示されます。

### 出力例

- **入力**:
  - 文字種: すべて選択
  - 文字数: 12
  - 単語: `Soccer`
- **出力 (一例)**: `c5r0c.eS8B>k`
  - `Soccer` が `50ccer` に変換され、他のランダムな文字と組み合わさってシャッフルされた、12文字のパスワードが生成されます。
  - 生成されるたびに結果は異なります。
