# シンプル・テックニュースリーダー

## 概要

このプロジェクトは、最新のテクノロジー関連ニュースをシンプルに表示するためのWebアプリケーションです。バックエンドはPython (Flask)で構築され、Dockerコンテナとして動作します。フロントエンドはHTML, CSS, JavaScriptで実装されており、バックエンドAPIから動的にニュースデータを取得して表示します。

## 主な機能

- 最新のテックニュース（サンプル）をリスト形式で表示します。
- ニュースのタイトルをクリックすると、元の記事ページが新しいタブで開きます。
- クリーンでミニマルなUI。

## 動作要件

- [Docker](https://www.docker.com/)
- [Docker Compose](https://docs.docker.com/compose/) (Docker Desktopに含まれています)

## 起動方法

1.  このリポジトリをクローンまたはダウンロードします。
2.  ターミナルでプロジェクトのルートディレクトリに移動します。
3.  以下のコマンドを実行して、Dockerコンテナをビルドし、バックグラウンドで起動します。

    ```bash
    docker-compose up -d --build
    ```
    *管理者権限が必要な場合は `sudo` を付けてください。*

4.  ビルドと起動が完了したら、Webブラウザで以下のURLにアクセスします。

    [http://localhost:5001](http://localhost:5001)

## 使い方

Webブラウザで [http://localhost:5001](http://localhost:5001) を開くと、ニュースタイトルの一覧が表示されます。

- **記事を読む**: 興味のあるニュースのタイトルをクリックしてください。記事の原文が掲載されているページが、新しいブラウザタブで開きます。

### 出力例

ブラウザには以下のような画面が表示されます。

```
最新テックニュース

・ 次世代AI、人間レベルの推論能力を達成か
・ 新しい量子コンピュータが計算速度の記録を更新
・ スタートアップ企業、画期的なバッテリー技術を発表
・ サイバーセキュリティの新たな脅威：AIによるフィッシング攻撃
・ 火星探査ミッション、重要な地質学的発見を報告
```
*(表示されるニュースはサンプルデータです)*
